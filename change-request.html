먼저 봐주실 것

아래 요청은 대부분 “화면마다 고유한 주소(URL)를 갖게 한다” 하나로 해결됩니다. 지금은 어느 메뉴로 이동해도 주소창이 그대로여서, 뒤로가기·새로고침·즐겨찾기·새 탭이 전부 막혀 있습니다. 이 구조만 바뀌면 1번과 2번은 함께 풀립니다.

요청 사항

01

화면마다 고유 주소 부여

필수
지금

메뉴를 눌러도 주소창이 바뀌지 않습니다. 그래서 새로고침(F5)하면 첫 화면으로 돌아가고, 특정 화면을 즐겨찾기하거나 링크로 공유할 수 없습니다.

요청

2단계 메뉴 화면마다 서로 다른 주소를 부여해 주세요.

확인 방법
  • 육안검사일지와 재고현황의 주소가 서로 다르다
  • 재고현황 주소를 복사해 새 창에 붙여넣으면 재고현황이 바로 열린다
  • F5로 새로고침해도 보고 있던 화면이 유지된다
02

뒤로가기와 현재 위치 표시

필수
지금

직전 화면으로 돌아갈 방법이 없어, 매번 홈으로 나갔다가 메뉴를 처음부터 다시 찾아 들어가야 합니다.

요청

화면 상단에 ← 뒤로 / → 앞으로 버튼과 현재 위치 경로(홈 › 원료수불 › 육안검사일지)를 넣어 주세요. 경로의 상위 항목을 누르면 그 메뉴로 이동합니다.

확인 방법
  • 육안검사일지 → 재고현황으로 이동한 뒤 뒤로가기를 누르면 육안검사일지로 돌아온다
  • 브라우저 자체의 뒤로가기 버튼도 똑같이 동작한다
03

좌측 메뉴 정리

권장
지금

1단계 11개와 2단계 10개가 한꺼번에 펼쳐져 화면 밖으로 넘어갑니다. 2단계는 앞에 붙은 - 하나로만 구분돼 상하위 관계가 잘 보이지 않습니다.

요청
  • 평소에는 1단계만 보이고, 누른 그룹 하나만 펼쳐지게
  • 메뉴 위쪽에 검색창 추가 (두 글자만 입력해도 걸러지도록)
  • 2단계는 들여쓰기와 세로선으로 단계가 보이게
  • 메뉴를 접어 아이콘만 남기는 버튼 추가
확인 방법
  • 노트북 화면(1366×768)에서 스크롤 없이 1단계 메뉴가 전부 보인다
  • 검색창에 “재고”를 입력하면 재고 관련 메뉴만 남는다

화면단만 수정하면 되는 항목이라 가장 먼저, 가장 적은 공수로 반영 가능할 것으로 봅니다.

04

여러 화면 동시에 열기

협의
지금

입고등록을 입력하다가 재고현황을 확인하러 가면, 입력하던 내용이 사라집니다.

요청

화면 상단에 탭을 두어 여러 화면을 동시에 열어두고, 탭을 오가도 입력값이 유지되게 해 주세요. (탭 최대 8개, 닫기·고정 가능)

확인 방법
  • 입고등록에 3건을 입력한 뒤 재고현황 탭으로 갔다가 돌아오면 입력값이 그대로 남아 있다

공수가 크다면 대안으로 — 1번(고유 주소)만 반영되면, 메뉴를 Ctrl+클릭 또는 우클릭으로 새 브라우저 탭에서 열기가 가능해집니다. 이것만으로도 실무 불편은 상당 부분 해소되니, 이 방식으로 먼저 검토해 주셔도 좋습니다.

진행 순서 제안

1차

01 · 02 · 03

주소 부여, 뒤로가기, 메뉴 정리. 현장에서 매일 겪는 불편이라 이번 단계에 함께 반영을 요청드립니다.

2차

04

동시 탭. 공수와 일정 확인 후 별도 협의합니다. 위의 새 브라우저 탭 방식으로 대체 가능한지 함께 검토 부탁드립니다.

회신 부탁드릴 내용

  1. 항목별 반영 가능 여부와, 어려운 항목은 그 사유
  2. 항목별 예상 소요 기간과 반영 일정
  3. 무상 개선 / 별도 비용 구분과 그 근거
  4. 현재 화면 전환이 어떤 방식(프레임 · 새로고침 · 단일 페이지)인지와, 주소 부여 시 영향 받는 범위

참고 시안은 동작 이해를 돕기 위한 예시이며, 화면 디자인이나 구현 방식을 지정하는 것은 아닙니다. 시안 속 데이터는 임의로 넣은 예시이고, 2단계 메뉴는 「원료수불/생산일지」만 실제 항목입니다.
