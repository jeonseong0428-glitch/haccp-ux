# 스마트 HACCP UX

스마트 HACCP 시스템의 화면 사용성 개선 자료입니다.
현장 워크숍에서 나온 사용자 발언을 근거로, 개선 시안과 개발 요청서를 정리했습니다.

**사이트** — https://jeonseong0428-glitch.github.io/haccp-ux/

| 문서 | 내용 |
| --- | --- |
| `index.html` | 표지 — 문제 요약과 문서 목록 |
| `interview.html` | 현장 목소리 — 워크숍 발언을 주제 8개로 정리, 원문 전사 포함 |
| `menu-proposal.html` | 메뉴 개편 시안 (클릭 가능한 프로토타입) |
| `change-request.html` | 공급기업 전달용 개발 요청서 |

## 요청 요약

**화면 이동·메뉴**

1. 화면마다 고유 주소 부여 — 뒤로가기·새로고침·즐겨찾기·링크 공유가 함께 해결됩니다.
2. 뒤로가기와 현재 위치 표시
3. 좌측 메뉴 정리 — 1단계 11개를 5개로 묶고 검색·즐겨찾기·건수 배지 추가
4. 여러 화면 동시 탭

**일지 작성 지원** (현장 워크숍에서 확인)

5. 해야 할 일지와 누락 알림
6. 작성 내용 검증 — 한계기준 위반·빈칸·불일치를 저장 시 표시
7. 법정 일정 안내 — 점검·검교정·교육훈련·실적보고·인증 갱신 기한

별건: 회수관리, 수출서류, 서식 직접 수정

## 로컬에서 보기

정적 HTML이라 별도 빌드가 없습니다. `index.html`을 브라우저로 열거나:

```
python -m http.server 8000
```

## 참고

- 표에 들어간 데이터는 전부 예시이며 실제 기록이 아닙니다.
- 현장 발언은 손글씨 화이트보드를 옮긴 것이라 일부 단어에 판독 오차가 있을 수 있습니다.
